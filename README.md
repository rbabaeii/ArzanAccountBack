# ArzanAccount Backend (NestJS + Prisma + irMarket API)

بک‌اند فروشگاه آنلاین اکانت‌های دیجیتال **ارزان اکانت**، توسعه داده شده با فریم‌ورک قدرتمند **NestJS**، **Prisma ORM** و اتصال مستقیم به وب‌سرویس **irMarket**.

---

## قابلیت‌های کلیدی (Core Features)

- **احراز هویت و امنیت (Authentication & RBAC):**
  - سیستم ورود و ثبت‌نام پیامکی بر مبنای رمز یکبارمصرف (OTP).
  - صدور و اعتبارسنجی توکن‌های امنیتی **JWT** با انقضای ۷ روزه.
  - سطح‌بندی دسترسی چندلایه پرسنل و مدیران:
    - `SUPER_ADMIN`: مدیریت کل سیستم، دسترسی‌ها و کاربران.
    - `CATALOG_MANAGER`: مدیریت محصولات، دسته‌بندی‌ها و انبار.
    - `FINANCE_ADMIN`: تنظیمات نرخ ارز، قیمت‌گذاری و تخفیف‌ها.
    - `SUPPORT_ADMIN`: مدیریت سفارشات و تحویل لایسنس.
    - `USER`: مشتریان و خریداران عادی فروشگاه.
- **یکپارچه‌سازی با irMarket:**
  - استعلام لحظه‌ای موجودی و قیمت دلاری محصولات از API مرجع.
  - همگام‌سازی خودکار کاتالوگ و ثبت سفارشات.
  - کیف پول دلاری و ایمنی در حالت توسعه (`MOCK_PURCHASE`).
- **موتور قیمت‌گذاری و ارز هوشمند:**
  - تبدیل خودکار قیمت پایه دلاری به تومان با نرخ روز و اعمال حاشیه سود پویا.
- **پایگاه‌داده منعطف با Prisma ORM:**
  - پشتیبانی از SQLite برای توسعه سریع محلی و PostgreSQL برای محیط پروداکشن (کانتینر داکر).

## راه‌اندازی سریع (Getting Started)

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. تنظیم متغیرهای محیطی
یک کپی از فایل `.env.example` ایجاد کرده و نام آن را به `.env` تغییر دهید:
```bash
cp .env.example .env
```

### ۳. مایگریشن و پر کردن داده‌های اولیه (Seed)
```bash
npm run prisma:generate
npm run prisma:push
npm run prisma:seed
```

### ۴. اجرای سرور توسعه
```bash
npm run start:dev
```
سرور به صورت پیش‌فرض بر روی پورت `http://localhost:4000` اجرا خواهد شد.

## ساختار ماژول‌ها (Modules Structure)

```
src/
├── auth/        # ماژول احراز هویت پیامکی، OTP و صدور JWT
├── catalog/     # کاتالوگ محصولات، دسته‌بندی‌ها و متادیتا
├── common/      # فیلترها، گاردها و ابزارهای مشترک
├── irmarket/    # کلاینت ارتباط مستقیم با وب‌سرویس irMarket
├── pricing/     # ماژول نرخ ارز و محاسبات قیمت‌گذاری
├── prisma/      # سرویس اتصال پایگاه‌داده Prisma
├── settings/    # تنظیمات عمومی سیستم و پیکربندی‌ها
├── sync/        # موتور همگام‌سازی کاتالوگ با سرویس مرجع
└── users/       # مدیریت کاربران، پرسنل و سطوح دسترسی (RBAC)
```
